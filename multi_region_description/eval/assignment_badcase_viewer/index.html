相邻人物互换与多人位置串扰 Badcases

如何判定“多人场景中的位置串扰”

  1. 对每张图计算原始位置对应的内容 F1：预测 #i 与 GT #i 配对。
  2. 枚举同一张图中预测描述到 GT bbox 的全部排列，找到内容 F1 最高的分配。
  3. 计算 assignment gap = 最优重排 F1 - 原始位置 F1。
  4. 若 assignment gap ≥ 0.10，说明描述重新分配给其他 bbox 后显著更合理，判为明显 bbox 分配错位。
  5. 再要求至少一个被移动的 bbox 对相邻：两框有面积重叠，或边缘距离 ≤ 两框平均对角线的 35%。
  6. N=2 归为“相邻人物描述互换”；N≥3 归为“多人场景中的位置串扰”。
assignment_gap ≥ 0.10 AND moved_bbox_pair_is_adjacent
该方法衡量的是“预测描述更适合另一个相邻 bbox”的强信号。它是自动统计口径，不等同于人工语义审核；F1 完全并列时保留最先达到最优的排列，避免制造无意义的假移动。
